0 de 7 pasos
💻

Antes de empezar: trae tu propio ordenador e intenta completar los siete pasos con calma. Si algo falla, no pasa nada: tendremos los datos ambientales ya descargados para que puedas seguir el taller.

1Crear una cuenta en Copernicus MarinePendiente⌄
  1. Haz clic en Copernicus Marine.
  2. Pulsa Register o Sign up.
  3. Rellena tus datos y confirma el correo que recibirás.
  4. Vuelve a la web e inicia sesión para comprobar que puedes entrar.
Guarda el correo y la contraseña: los necesitarás en el paso 4.
2Instalar R y RStudioPendiente⌄

Son dos programas distintos y hacen falta los dos. Instala primero R y después RStudio.

Instalar R

  1. Haz clic en CRAN.
  2. Pulsa Windows, macOS o Linux, según tu ordenador.
  3. Descarga el instalador, ábrelo y pulsa Next / Siguiente dejando todas las opciones por defecto.

Instalar RStudio

  1. Haz clic en RStudio Desktop.
  2. Descarga la versión gratuita para tu sistema operativo.
  3. Abre el instalador y deja las opciones por defecto.
  4. Abre RStudio: en Windows, búscalo desde Inicio; en Mac, desde Aplicaciones.

En la zona inferior izquierda (Console), copia, pega y pulsa Enter:

print("SDM workshop")

Si aparece [1] "SDM workshop", está bien instalado.

3Instalar Git y comprobar BashPendiente⌄

Git descarga los archivos del taller y también instala Bash, necesario para la descarga automática.

Windows

  1. Haz clic en Git y pulsa Download for Windows.
  2. Abre el archivo descargado, normalmente Git-…exe.
  3. Pulsa Next sin cambiar nada hasta llegar a la pantalla titulada “Adjusting your PATH environment”.
En esa pantalla, marca exactamente:
“Git from the command line and also from 3rd-party software”.
Es la opción intermedia. Después: Next → Install → Finish.
  1. Pulsa Inicio, escribe Git Bash y abre la aplicación.

macOS

En el mismo enlace, descarga el instalador para macOS, ábrelo y sigue los pasos. Después abre Terminal desde Aplicaciones → Utilidades.

En Git Bash (Windows) o Terminal (macOS), copia, pega y pulsa Enter:

bash --version

Debe aparecer una línea que empieza por GNU bash.

4Instalar Miniconda y Copernicus MarinePendiente⌄

Windows

  1. Haz clic en Miniconda y descarga el instalador para Windows.
  2. Ábrelo, pulsa Next y elige Just Me (recommended).
  3. Deja la carpeta que aparece por defecto y pulsa Next.
Pantalla clave: en “Advanced Installation Options”, marca “Add Miniconda3 to my PATH environment variable”. Después: Install → Finish.

Cierra Git Bash si estaba abierto.
  1. Pulsa Inicio, escribe Miniconda Prompt y abre esa aplicación.

macOS

En la misma web, descarga el instalador de Miniconda correspondiente a tu Mac (Apple Silicon o Intel), instálalo dejando las opciones por defecto y abre Terminal.

En Miniconda Prompt (Windows) o Terminal (macOS), copia, pega y pulsa Enter:

conda install -c conda-forge copernicusmarine -y

Cuando termine por completo, copia, pega y pulsa Enter:

copernicusmarine login

Introduce el correo y contraseña del paso 1. Al escribir la contraseña no se ven letras: es normal.

5Comprobar Copernicus MarinePendiente⌄

En la misma ventana del paso anterior, copia, pega y pulsa Enter:

copernicusmarine --help

Solo Windows: abre ahora Git Bash desde Inicio, repite exactamente el mismo comando y pulsa Enter. Si en ambas ventanas aparece un texto largo de ayuda, la configuración está lista.

6Descargar el repositorio del tallerPendiente⌄

Abre Git Bash (Windows) o Terminal (macOS). Copia el primer bloque, pégalo en la ventana y pulsa Enter. Espera a que termine. Después repite con el segundo bloque.

git clone https://github.com/jazelouled/EndToEndSDM_SECWorkshop_2026.git
cd EndToEndSDM_SECWorkshop_2026
7Instalar los paquetes de RPendiente⌄

Abre RStudio. Haz clic dentro de Console (abajo a la izquierda), pulsa Copiar, pega el bloque completo y pulsa Enter. Puede tardar varios minutos: no cierres RStudio mientras esté trabajando.

cran_packages <- c("argosfilter", "caret", "corrplot", "data.table", "dplyr", "geosphere", "ggplot2", "grid", "here", "lubridate", "patchwork", "pdp", "pROC", "purrr", "randomForest", "ranger", "raster", "readr", "rnaturalearth", "rnaturalearthdata", "sf", "stringr", "terra", "tidyr", "tidyverse", "viridis")
missing_cran <- setdiff(cran_packages, rownames(installed.packages()))
if (length(missing_cran) > 0) install.packages(missing_cran, repos = "https://cloud.r-project.org/", dependencies = TRUE)
if (!requireNamespace("remotes", quietly = TRUE)) install.packages("remotes", repos = "https://cloud.r-project.org/")
if (!requireNamespace("aniMotum", quietly = TRUE)) install.packages("aniMotum", repos = c("https://cloud.r-project.org/", "https://ianjonsen.r-universe.dev/"), dependencies = TRUE)
if (!requireNamespace("availability", quietly = TRUE)) remotes::install_github("AustralianAntarcticDivision/availability")
