Prepara tu ordenador para el taller SDM

Una guía paso a paso para dejar listo R, Copernicus Marine y la descarga automática de datos ambientales.

Tu preparación

0 de 7 pasos

Antes de empezar: trae tu propio ordenador e intenta completar estos pasos antes del taller. Si algo falla, no te preocupes: tendremos los datos ambientales ya descargados para que puedas seguir la sesión.

1Crear una cuenta en Copernicus MarinePendiente⌄

Crea una cuenta gratuita en Copernicus Marine. Guarda tu nombre de usuario y contraseña: los necesitarás para descargar los datos ambientales.

2Instalar R y RStudioPendiente⌄

Si todavía no los tienes, instala R y RStudio Desktop.

Después abre RStudio y ejecuta:

print("SDM workshop")

Si el texto aparece en la consola, está todo correcto.

3Instalar Git y comprobar BashPendiente⌄

Instala Git.

Solo Windows: durante la instalación, selecciona la opción que permite usar Git desde la línea de comandos y desde programas de terceros. Esto instalará también Git Bash, necesario para el script de descarga automática.

Abre Git Bash (Windows) o Terminal (macOS/Linux) y comprueba:

bash --version
4Instalar Miniconda y Copernicus Marine ToolboxPendiente⌄

Descarga e instala Miniconda.

Solo Windows — paso importante: durante la instalación, marca Add Miniconda3 to my PATH environment variable. Es necesario para que copernicusmarine pueda ejecutarse desde Git Bash y desde el script automático del taller. Después, cierra y vuelve a abrir todas las terminales.

Abre Miniconda Prompt (Windows) o Terminal (macOS/Linux) y ejecuta:

conda install -c conda-forge copernicusmarine -y

Cuando termine, inicia sesión:

copernicusmarine login

Al escribir tu contraseña no aparecerán caracteres en pantalla: es normal.

5Comprobar Copernicus MarinePendiente⌄

En una terminal, ejecuta:

copernicusmarine --help

En Windows, repite exactamente el mismo comando desde Git Bash. Si aparece la ayuda de Copernicus Marine, la configuración está lista.

6Descargar el repositorio del tallerPendiente⌄

Abre una terminal, descarga el repositorio y entra en la carpeta:

git clone https://github.com/jazelouled/ModelosDistribucionEspecies_CMEMS_Malaga2026.git
cd ModelosDistribucionEspecies_CMEMS_Malaga2026
7Instalar los paquetes de RPendiente⌄

Abre RStudio, copia el bloque completo en la consola y ejecútalo. La instalación puede tardar varios minutos, especialmente para aniMotum.

cran_packages <- c(
  "argosfilter", "caret", "corrplot", "data.table", "dplyr", "geosphere",
  "ggplot2", "grid", "here", "lubridate", "patchwork", "pdp", "pROC",
  "purrr", "randomForest", "ranger", "raster", "readr", "rnaturalearth",
  "rnaturalearthdata", "sf", "stringr", "terra", "tidyr", "tidyverse", "viridis"
)

missing_cran <- setdiff(cran_packages, rownames(installed.packages()))

if (length(missing_cran) > 0) {
  install.packages(missing_cran, repos = "https://cloud.r-project.org/", dependencies = TRUE)
}

if (!requireNamespace("remotes", quietly = TRUE)) {
  install.packages("remotes", repos = "https://cloud.r-project.org/")
}

if (!requireNamespace("aniMotum", quietly = TRUE)) {
  install.packages(
    "aniMotum",
    repos = c("https://cloud.r-project.org/", "https://ianjonsen.r-universe.dev/"),
    dependencies = TRUE
  )
}

if (!requireNamespace("availability", quietly = TRUE)) {
  remotes::install_github("AustralianAntarcticDivision/availability")
}
